# Architecture Decision Records (ADR) Index

This directory contains the architectural decision records for this repository based on the [MADR format](https://adr.github.io/madr/).

When proposing an architectural change or introducing a new package/service:
1. Copy [template.md](./template.md) to a new file named `NNNN-short-title.md`.
2. Document the context, options considered, and chosen solution.
3. Add the record to the table below.
